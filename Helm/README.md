# Helm

The official Genosyn Helm chart lives in [`genosyn/`](./genosyn/). It is
published as an OCI artifact to `oci://ghcr.io/genosyn/charts/genosyn` by
`.github/workflows/chart.yml` on every release tag, with the chart version
tracking the repo `VERSION` file. Start with the
[chart README](./genosyn/README.md) for the quickstart, values, sandbox
notes, and the multi-tenant checklist.
